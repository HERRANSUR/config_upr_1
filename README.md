# Эмулятор командной строки UNIX

## 1. О программе
Данная программа представляет собой эмулятор интерфейса командной строки UNIX-подобной операционной системы. Эмулятор работает в двух режимах: интерактивном (REPL) и пакетном (выполнение команд из файла-скрипта).

Вся виртуальная файловая система (VFS) загружается из JSON-файла в оперативную память при старте приложения. Все операции над каталогами и файлами выполняются в памяти, без создания или изменения реальных файлов на физическом диске.

### Архитектурные особенности:
- **Модульная структура:** каждая команда вынесена в отдельную подфункцию (`cmd_`), функция-диспетчер - `execute_command`.
- **Универсальная навигация:** функция `resolve_path` обеспечивает корректную обработку абсолютных и относительных путей, а также переходов по `.`, `..` и `/`.

## 2. Параметры командной строки

Запуск программы регулируется флагами командной строки:
- `--vfs` (*обязательный*) — путь к JSON-файлу со структурой виртуальной файловой системы.
- `--script` (*опциональный*) — путь к текстовому файлу с набором команд для автоматического выполнения.

## 3. Поддерживаемые функции и команды

На текущем этапе полностью реализован базовый набор команд UNIX:

- `ls [path]` — просмотр содержимого директории. Если путь не указан, выводит содержимое текущего каталога. Поддерживает абсолютные и относительные пути, а также передачу имени конкретного файла.
- `cd [path]` — смена текущей рабочей директории. Поддерживает относительные пути, абсолютные пути (начинающиеся с `/`), переходы на уровень вверх (`..`) и в текущую папку (`.`). Вызов `cd` без аргументов или `cd /` возвращает пользователя в корень VFS.
- `pwd` — вывод абсолютного пути к текущей рабочей директории (не принимает аргументов).
- `tac [path]` — вывод содержимого текстового файла в обратном порядке строк (задом наперед). Если путь не передан, переходит в режим интерактивного чтения с клавиатуры.
- `exit` — завершение работы эмулятора и выход из консоли (не принимает аргументов).

## 4. Виртуальная файловая система (VFS)

Файловая система представляется в виде вложенной структуры JSON, где словари обозначают каталоги, а текстовые строки — содержимое файлов:

```json
{
  "documents": {
    "projects": {
      "lab1": {
        "info.txt": "123\n555",
        "notes.txt": "test"
      },
      "readme.txt": "hello"
    },
    "text.txt": "abc"
  },
  "downloads": {
    "file.txt": "data"
  }
}
```

Для тестирования работы с VFS в проекте используются JSON-файлы:
- `vfs_min.json` — минимальный вариант VFS (пустая структура) для базовых тестов.
- `vfs.json` — многоуровневая VFS с глубиной вложенности папок не менее 3 уровней и тестовыми файлами.

## 5. Обработка ошибок

В программе предусмотрена защита от нестандартных ситуаций и сбоев:

- **Ошибки VFS:** если файл VFS не найден или содержит некорректный JSON, программа выводит понятное сообщение и корректно завершает работу при старте.
- **Ошибки навигации и путей:** 
  - Попытка перехода в несуществующую папку через `cd` выводит: `Ошибка: cd: нет такого каталога '<path>'`.
  - Попытка применить `cd` к файлу вместо каталога выводит аналогичную ошибку.
  - Попытка посмотреть содержимое несуществующего пути через `ls` выводит: `Ошибка: ls: нет такого файла или каталога '<path>'`.
  - Попытка прочитать через `tac` директорию вместо файла выводит: `Ошибка: tac: '<path>' является каталогом`.
  - Попытка прочитать несуществующий файл через `tac` выводит: `Ошибка: tac: файл '<path>' не найден`.
- **Проверка аргументов:** команды `pwd` и `exit` проверяют наличие лишних аргументов и выводят ошибку при их обнаружении.
- **Ошибки скрипта:** при встрече неизвестной команды или возникновении ошибки выполнения любой из команд сценарий немедленно останавливается.
- **Пустой ввод:** при нажатии `Enter` без ввода команды программа пропускает итерацию и запрашивает ввод заново.
- **Лишние пробелы:** пробелы в начале, конце и между аргументами корректно обрабатываются с помощью `.strip().split()`.
- **Перехват сигналов:** экстренное завершение через `Ctrl+C` или `Ctrl+D` перехватывается без вывода аварийного стека Python.

## 6. Инструкция по запуску и тестированию

### Запуск в интерактивном режиме (REPL)
```bash
python src/main.py --vfs vfs.json
```

### Запуск в режиме выполнения скрипта
```bash
python src/main.py --vfs vfs.json --script script.txt
```

### Главный запуск всех тестов
Для автоматической проверки всех сценариев выполните командный файл:
```powershell
.\run.bat
```
