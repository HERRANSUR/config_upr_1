# Эмулятор командной строки UNIX

## 1. О программе
Данная программа представляет собой эмулятор CLI (интерфейса командной строки) UNIX-подобной операционной системы. Эмулятор работает в двух режимах: интерактивном (REPL) и пакетном (выполнение команд из файла-скрипта).

Вся виртуальная файловая система (VFS) загружается из JSON-файла в оперативную память при старте приложения. Все операции выполняются в памяти, без создания или изменения реальных файлов на диске.

Проект разработан в рамках лабораторной работы по дисциплине «Конфигурационное управление».

## 2. Параметры командной строки

Запуск программы регулируется флагами командной строки:
- `--vfs` (*обязательный*) — путь к JSON-файлу со структурой виртуальной файловой системы.
- `--script` (*опциональный*) — путь к текстовому файлу с набором команд для автоматического выполнения.

## 3. Поддерживаемые функции и команды

На текущем этапе реализован базовый каркас интерпретатора и заглушки для следующих команд:

- `ls` — просмотр содержимого текущей директории. Принимает аргументы (например, флаги или пути к папкам). На этапе прототипа выводит сообщение о вызове заглушки с переданными аргументами.
- `cd <path>` — смена текущей рабочей директории. Принимает путь к целевой папке. На этапе прототипа выводит сообщение о вызове заглушки.
- `exit` — завершение работы эмулятора и выход из консоли.

## 4. Виртуальная файловая система (VFS)

Для тестирования работы с VFS в проекте созданы два JSON-файла:
- `vfs_min.json` — минимальный вариант VFS (пустая структура) для базовых тестов.
- `vfs.json` — многоуровневая VFS с глубиной вложенности папок не менее 3 уровней и тестовыми файлами.

## 5. Обработка ошибок

В программе предусмотрена защита от нестандартных ситуаций и сбоев:

- **Ошибки VFS:** если файл VFS не найден или содержит некорректный JSON, программа выводит сообщение об ошибке и корректно завершает работу.
- **Ошибки скрипта:** при встрече неизвестной команды или неверных аргументов выполнение файла скрипта немедленно прерывается.
- **Пустой ввод:** если пользователь просто нажимает Enter, программа не вылетает, а запрашивает ввод заново.
- **Лишние пробелы:** пробелы в начале и конце строки автоматически срезаются.
- **Неизвестные команды:** при вводе любой некорректной команды выводится понятное сообщение об ошибке.
- **Горячие клавиши:** экстренное завершение через `Ctrl+C` или `Ctrl+D` перехватывается без вывода стека ошибок Python.
