# Эмулятор командной строки UNIX

## 1. О программе
Данная программа представляет собой эмулятор CLI (интерфейса командной строки) UNIX-подобной операционной системы. Эмулятор работает в режиме REPL (Read-Eval-Print Loop), то есть принимает команды от пользователя в бесконечном цикле, обрабатывает их и выводит результат.

Проект разработан в рамках лабораторной работы по дисциплине «Конфигурационное управление».

## 2. Поддерживаемые функции и команды

На текущем этапе реализован базовый каркас интерпретатора и заглушки для следующих команд:

- `ls` — просмотр содержимого текущей директории. Принимает аргументы (например, флаги или пути к папкам). На этапе прототипа выводит сообщение о вызове заглушки с переданными аргументами.
- `cd <path>` — смена текущей рабочей директории. Принимает путь к целевой папке. На этапе прототипа выводит сообщение о вызове заглушки.
- `exit` — завершение работы эмулятора и выход из консоли.

## 3. Обработка ошибок

В программе предусмотрена защита от нестандартных ситуаций и сбоев:

- **Пустой ввод:** если пользователь просто нажимает Enter, программа не вылетает, а запрашивает ввод заново.
- **Лишние пробелы:** пробелы в начале и конце строки автоматически срезаются.
- **Неизвестные команды:** при вводе любой некорректной команды выводится понятное сообщение об ошибке, без падения программы.
- **Горячие клавиши:** экстренное завершение через `Ctrl+C` или `Ctrl+D` перехватывается, позволяя программе завершиться корректно без вывода стека ошибок Python.
